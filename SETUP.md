# Ruddy2310 Profile README — Setup

1. Create a **public** GitHub repository named exactly `Ruddy2310`.
2. Put all files from this folder into that repository.
3. Run:
   `python scripts/radar.py`
4. Commit and push.
5. In GitHub → Settings → Actions → General, allow workflows to have **Read and write permissions**.
6. Run the workflows once manually from the Actions tab.
7. Replace `YOUR_LINKEDIN` and `YOUR_EMAIL` in `README.md`.
8. Replace the four featured projects with your real repository names/links.
9. Add your portrait later; the PDF guide's dot-matrix portrait step can then be added.

This starter intentionally avoids copying the guide's original private scripts. It recreates the same overall architecture with a small custom radar generator.
